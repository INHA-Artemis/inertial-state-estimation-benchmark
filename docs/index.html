IMU 기반 상태추정 연구

Inertial State Estimation Benchmark

같은 상태와 입력을 사용해 EKF, UKF, PF, ESKF, InEKF를 비교하고, IMU-only dead reckoning과 위치 update, Small TCN 속도 추정을 실험한 코드입니다.

연구 내용 필터 구조 필터 결과 학습 결과 실행 방법 주의사항 이론과 구현 보고서 PDF

연구 내용

2026년 6월 22일 이후 진행한 상태추정 연구를 한 저장소에서 실행할 수 있도록 정리했습니다. IMU bias를 한 번 정해 고정했을 때의 dead reckoning, 위치 측정을 넣었을 때의 필터 차이, 회전량에 따른 InEKF 성능, 이전 비행으로 학습한 속도 측정을 차례로 확인했습니다.

공통 필터

모든 필터에 같은 IMU, 초기값, 위치 측정과 평가식을 사용합니다.

IMU-only와 위치 update

EuRoC에서 위치 측정 유무에 따른 위치와 roll, pitch, heading 오차를 비교합니다.

IMU 속도 학습

Runs 3/4/9/10으로 학습하고 Run 5에서는 시작 상태와 IMU만 사용합니다.

InEKF만 사용한다고 IMU-only 위치 drift가 없어지지는 않았습니다. 현재 실험에서는 학습 속도를 InEKF에 넣었을 때 위치보다 자세 오차가 더 크게 개선됐습니다.

진행 순서

  1. 상태 정의 통일R, v, p, gyro bias, accel bias와 15차원 오차상태를 정했습니다.
  2. 필터 구조 통일EKF·UKF·PF·ESKF·InEKF의 predict, update, output 형식을 맞췄습니다.
  3. 고정 bias IMU 적분시작 구간에서 bias를 한 번 계산한 뒤 전체 구간에 같은 값을 사용했습니다.
  4. 위치 측정 비교EuRoC와 합성 데이터에서 모든 필터에 같은 위치 update를 넣었습니다.
  5. 학습 속도 비교36,003-parameter Small TCN이 최근 2초의 IMU에서 속도를 예측합니다.
  6. 코드 사용 구조 정리Python API, 명령행 실행기, test, 결과 파일과 사용 문서를 추가했습니다.

필터 구조

IMU 입력

[ax, ay, az, gx, gy, gz]

Pose 출력

[px, py, pz, roll, pitch, yaw]

상태: {R, v, p, bg, ba} → 오차상태: [δθ, δv, δp, δbg, δba] ∈ R15

필터자세와 불확실성 표현현재 용도
EKFQuaternion을 포함한 16차원 상태기본 비교 방법

PFQuaternion particle과 위치 likelihood비가우시안 비교
ESKFRotation matrix와 15차원 error injection현재 발산 원인 확인 중

IMU-only에서는 EKF와 InEKF의 궤적이 거의 같았고 모두 발산했습니다. 2 Hz 위치 update에서는 EKF 0.110 m, InEKF 0.114 m였습니다. 실행시간은 InEKF 8.51초, EKF 15.90초였습니다. 위치 측정은 실제 GPS가 아니라 GT 위치에 noise를 추가해 만든 값입니다.

회전 운동 비교

noise, bias, 실험 시간과 1 Hz 위치 update는 같게 두고 회전 운동만 세 단계로 바꿨습니다. 회전량이 커질수록 InEKF가 EKF보다 계속 좋아지지는 않았습니다. 이 관계는 실제 세 플랫폼에서 같은 위치 측정 조건을 적용해 더 확인해야 합니다.

설치와 실행

git clone https://github.com/INHA-Artemis/inertial-state-estimation-benchmark.git
cd inertial-state-estimation-benchmark
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[test,learned]"

python examples/basic_filter_loop.py
state-estimation-run-all --config config/euroc.yaml --filters ekf ukf pf inekf
state-estimation-cf231-tcn --dataset data/cf231_leave_one_out/csv
python -m pytest -q

데이터 파일의 위치와 필요한 파일명은 저장소의 DATASETS.md에 적어 두었습니다.

결과를 볼 때 주의할 점

  • Pohang: 기존 결과는 baseline 위치를 update와 평가에 같이 사용해 위치 오차가 작게 나올 수 있습니다.
  • UrbanNav: 8월 4일 발표 수치만 남아 있고 당시 loader와 설정은 현재 저장소에 없습니다.
  • ESKF: EuRoC에서 발산해 error injection과 좌표계를 다시 확인해야 합니다.
  • 플랫폼 비교: 이동로봇, 수상선, 드론에 같은 GNSS 조건을 적용한 실제 데이터 비교는 아직 남아 있습니다.
