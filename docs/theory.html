필터 이론과 구현

이 문서는 EKF, UKF, PF, ESKF, InEKF를 구현할 때 어떤 state를 쓰고, 어떤 순서로 predict/update를 구성하며, 특히 InEKF에서 error와 Jacobian을 어떻게 정의해야 하는지 설명합니다.

상태 정의 운동 모델 필터별 구조 InEKF 데이터 loader 측정 update 실행 결과

문서 범위

같은 관성 상태추정 문제를 각 필터에서 어떻게 구현했는지 설명합니다. EKF, UKF, PF, ESKF는 전체 계산 흐름을 비교하고, InEKF는 invariant error, Lie algebra correction, analytic Jacobian을 조금 더 자세히 다룹니다.

공통 입력

IMU control input은 다음 순서로 통일합니다.

control = [ax, ay, az, gx, gy, gz]

공통 출력

모든 필터는 외부 비교용으로 6D pose를 반환합니다.

estimate_pose() -> [px, py, pz, roll, pitch, yaw]

상태 정의

공통 nominal state는 position, velocity, attitude, gyro bias, accelerometer bias로 구성됩니다.

$$x = [p,\ v,\ R/q,\ b_g,\ b_a]$$
  • $p \in \mathbb{R}^3$: position
  • $v \in \mathbb{R}^3$: velocity
  • $R \in SO(3)$ 또는 unit quaternion $q$: attitude
  • $b_g \in \mathbb{R}^3$: gyroscope bias
  • $b_a \in \mathbb{R}^3$: accelerometer bias

ESKF, UKF, PF, InEKF 계열에서 attitude uncertainty는 3D local rotation error로 표현합니다.

$$\delta x = [\delta\theta,\ \delta v,\ \delta p,\ \delta b_g,\ \delta b_a]$$
Quaternion EKF는 quaternion 4성분을 Kalman state에 직접 포함하므로 내부적으로는 16D additive state입니다. 반면 Quaternion UKF/PF는 quaternion을 nominal attitude로 저장하고, covariance 또는 particle perturbation은 15D local tangent error를 사용합니다.

IMU 운동 모델

IMU predict 단계에서는 bias를 제거한 angular velocity와 acceleration을 사용합니다.

$$\omega = \omega_{imu} - b_g, \qquad a = a_{imu} - b_a$$

기본 propagation은 다음과 같습니다.

$$R_{k+1} = R_k \exp(\omega\Delta t)$$ $$a_{world} = R_k a + g$$ $$v_{k+1} = v_k + a_{world}\Delta t$$ $$p_{k+1} = p_k + v_k\Delta t + \frac{1}{2}a_{world}\Delta t^2$$

Quaternion 기반 필터에서는 같은 회전 increment를 quaternion exponential로 적용합니다.

$$q_{k+1} = q_k \otimes \operatorname{Exp}_q(\omega\Delta t)$$

필터별 구현 구조

모든 필터는 같은 IMU input과 같은 position measurement를 받지만, attitude와 uncertainty를 다루는 방식이 다릅니다. 아래 표는 각 필터를 구현할 때 핵심적으로 확인해야 하는 부분입니다.

필터 구현할 때 확인할 부분 자세 처리
Quaternion EKF State vector에 quaternion 4성분을 직접 넣고, predict/update 후 unit norm constraint를 유지하기 위해 normalize합니다. Additive quaternion state, internal 16D
Quaternion UKF 15D local tangent error에서 sigma point를 만들고, attitude sigma point만 quaternion exponential로 nominal quaternion에 적용합니다. $q_i = q \otimes Exp_q(\delta\theta_i)$
Quaternion PF Particle별로 $p, v, q, b_g, b_a$를 유지하고, IMU propagation은 batch로 처리합니다. Measurement update는 likelihood로 particle weight를 갱신합니다. Particle별 unit quaternion, weighted quaternion mean
Rotation ESKF Nominal state는 nonlinear하게 propagation하고, Kalman filter는 small error state를 추정합니다. Update 후 error를 nominal state에 injection합니다. $R \leftarrow R\exp(\delta\theta)$
InEKF Rotation, velocity, position을 하나의 Lie group state로 묶고, error를 group perturbation으로 정의합니다. Jacobian은 이 invariant error 정의와 일관되게 구성해야 합니다. $X \leftarrow X\operatorname{Exp}(\delta\xi)$

공통 predict와 update 순서

1. Bias removal
$\omega = \omega_{imu}-b_g$, $a=a_{imu}-b_a$
2. Nominal propagation
Update $R/q$, $v$, $p$ with IMU motion model
3. Uncertainty propagation
EKF/ESKF/InEKF: Jacobian, UKF: sigma covariance, PF: particle spread
4. Measurement update
Position residual or likelihood updates state belief

필터별 설명 범위

EKF, UKF, PF, ESKF는 핵심 구현 구조만 설명하고 InEKF는 더 자세히 다룹니다. InEKF에서는 error를 어떤 좌표계에서 정의하는지, correction을 어떻게 group에 적용하는지, 그리고 그 정의와 맞는 Jacobian을 어떻게 구성하는지가 성능과 일관성의 핵심입니다.

InEKF의 error, correction, Jacobian

InEKF의 핵심은 단순히 rotation을 matrix로 저장하는 것이 아닙니다. 중요한 것은 nominal state를 Lie group 위에서 propagation하고, error state를 Lie algebra에서 정의한 뒤, 그 error 정의와 일관된 Jacobian을 쓰는 것입니다.

1. Lie group 상태 정의

먼저 rotation, velocity, position을 하나의 matrix state로 묶습니다.

$$X = \begin{bmatrix} R & v & p \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{bmatrix},\qquad x = [X,\ b_g,\ b_a]$$

여기서 $R, v, p$는 따로따로 보관할 수도 있지만, InEKF에서는 이들을 $SE_2(3)$ 형태의 group state로 보고 propagation과 correction을 구성합니다.

2. Invariant error 정의

현재 구현은 right perturbation convention을 사용합니다. 즉 error는 nominal state 오른쪽에 곱해지는 작은 Lie algebra vector입니다.

$$X^+ = X\operatorname{Exp}(\delta\xi),\qquad \delta x = [\delta\theta,\ \delta v,\ \delta p,\ \delta b_g,\ \delta b_a]$$

이 정의를 정하면 update에서 correction을 적용하는 방식도 자동으로 정해집니다.

$$R \leftarrow R\exp(\delta\theta),\qquad v,p \leftarrow \text{group correction from }\delta\xi, \qquad b_g,b_a \leftarrow b + \delta b$$
InEKF를 구현하기 전에 left/right error convention부터 정해야 합니다. convention이 바뀌면 measurement Jacobian, process Jacobian, correction 방향이 모두 같이 바뀌어야 합니다.

3. Nominal state 전파

IMU input에서 bias를 제거한 뒤, nominal state는 nonlinear motion model로 직접 propagation합니다.

$$\omega = \omega_{imu} - b_g,\qquad a = a_{imu} - b_a$$ $$R_{k+1} = R_k\exp(\omega\Delta t)$$ $$v_{k+1} = v_k + (R_k a + g)\Delta t$$ $$p_{k+1} = p_k + v_k\Delta t + \frac{1}{2}(R_k a + g)\Delta t^2$$

회전 중 가속도 적분을 더 일관되게 처리할 때는 SO(3) Jacobian/Gamma 항을 사용할 수 있습니다.

$$v_{k+1} = v_k + (R_k\Gamma_1(\phi)a + g)\Delta t$$ $$p_{k+1} = p_k + v_k\Delta t + R_k\Gamma_2(\phi)a\Delta t^2 + \frac{1}{2}g\Delta t^2$$ $$\phi = \omega\Delta t$$

4. Error covariance 전파

Kalman covariance는 nominal state 자체가 아니라 error state에 대해 propagation됩니다. 따라서 process Jacobian $\Phi$는 다음 관계를 근사해야 합니다.

$$\delta x_{k+1} \approx \Phi_k\delta x_k + G_kn_k$$ $$P_{k+1} = \Phi_kP_k\Phi_k^T + Q_d$$

여기서 중요한 점은 $\Phi_k$가 일반 Euclidean state difference가 아니라, 위에서 정의한 right-invariant error의 변화량을 설명해야 한다는 것입니다.

5. Finite difference와 analytic Jacobian

방법 $\Phi$ 계산 특징
Finite difference 각 error basis $e_i$를 group에 perturbation하고, propagation 후 Lie-minus로 차이를 계산합니다. 구현이 직관적이지만 15D column마다 propagation이 필요해 느립니다.
Analytic Jacobian IMU motion model과 right-error convention에서 closed-form error transition을 유도합니다. 동일한 error 정의를 유지하면서 runtime을 크게 줄일 수 있습니다.

Finite difference의 개념은 다음과 같습니다.

$$\Phi_{:,i} \approx \frac{\operatorname{Log}\left(f(X\operatorname{Exp}(+\epsilon e_i))^{-1}_{\text{error}}\, f(X)\right) - \operatorname{Log}\left(f(X\operatorname{Exp}(-\epsilon e_i))^{-1}_{\text{error}}\, f(X)\right)}{2\epsilon}$$

실제 코드에서는 이 과정을 analytic 형태로 대체합니다. 핵심은 단순히 미분식을 빠르게 만드는 것이 아니라, right perturbation으로 정의한 error와 같은 좌표계의 Jacobian을 써야 한다는 점입니다.

6. Measurement Jacobian

Position measurement는 다음 residual을 사용합니다.

$$r = z_p - \hat{p}$$

하지만 $H$는 단순히 $[I,0,0]$로 끝나지 않습니다. Right perturbation에서 $p$가 어떻게 변하는지에 맞춰 measurement Jacobian을 정의해야 합니다.

$$H = \frac{\partial h(X\operatorname{Exp}(\delta\xi))}{\partial \delta x}\bigg|_{\delta x=0}$$

현재 analytic 구현에서는 right perturbation convention에 맞춰 position block이 rotation과 결합됩니다.

$$H_p[:,\delta p] \approx R$$

7. Correction과 bias update

Kalman update로 error를 얻은 뒤 correction은 group part와 bias part로 나눠 적용합니다.

$$K = PH^T(HPH^T + R_m)^{-1},\qquad \delta x = Kr$$ $$X \leftarrow X\operatorname{Exp}(\delta\xi)$$ $$b_g \leftarrow b_g + \delta b_g,\qquad b_a \leftarrow b_a + \delta b_a$$
Position measurement가 bias를 직접 측정하지는 않습니다. 그러나 $P$ 안의 cross-correlation 때문에 position residual이 attitude, velocity, bias correction으로 전달될 수 있습니다. measurement가 없는 dead reckoning에서는 이 residual이 사라지므로 bias를 새로 추정하기 어렵습니다.

8. ESKF와 InEKF의 차이

항목 Rotation ESKF InEKF
상태 $p, v, R$를 nominal state로 따로 보관 $R, v, p$를 Lie group matrix $X$로 묶음
오차 Small local error injected into nominal state Invariant group error defined by left/right perturbation
Jacobian 일반 error-state dynamics 기준 Invariant error dynamics 기준
주요 특징 구현이 직관적이고 IMU ESKF 표준 구조와 가까움 Group geometry와 error propagation의 일관성을 더 강하게 유지

구현 확인 사항

  • Jacobian을 작성하기 전에 left-invariant와 right-invariant 중 어떤 error를 쓸지 정합니다.
  • Plus, minus, process Jacobian, measurement Jacobian에 같은 convention을 사용합니다.
  • Euler angle을 더하지 않고 Lie group 위에서 nominal $X$를 전파합니다.
  • Bias는 additive update를 사용하고, residual의 영향은 covariance cross-correlation으로 전달합니다.
  • Analytic Jacobian은 finite-difference 결과와 비교한 뒤 실행시간 평가에 사용합니다.

각 데이터는 CommonDataset 형식으로 변환한 뒤 같은 runner와 filter registry를 사용합니다. 따라서 데이터셋마다 파일 형식은 달라도 filter 입장에서는 timestamps, controls, ground_truth, position_measurements를 같은 방식으로 받습니다.

측정 update

Sparse update benchmark에서는 GT position을 pseudo-position measurement로 사용합니다.

$$z_p = p_{GT} + n_p$$

Kalman 계열 필터의 position residual은 다음과 같습니다.

$$r = z_p - \hat{p}, \qquad \delta x = K r$$

Position measurement는 bias를 직접 측정하지 않지만, covariance cross-correlation을 통해 position residual이 velocity, attitude, bias correction으로 전달될 수 있습니다. Dead reckoning에서는 measurement residual이 없으므로 bias correction 근거가 사라집니다.

속도와 자세 측정

기본 설정은 position-only update입니다. Pohang과 i2Nav처럼 velocity 또는 attitude 값이 함께 있는 데이터에서는 설정 파일에서 추가 measurement를 선택할 수 있습니다. 

measurements:
  use_position: true
  use_velocity: true
  use_attitude: true
  velocity_measurement_noise_diag: [1.0e-2, 1.0e-2, 1.0e-2]
  attitude_measurement_noise_diag: [7.6e-5, 7.6e-5, 7.6e-5]
Measurement Kalman-style filters Particle Filter
Position $r_p = z_p - \hat p$로 position residual update $p(z_p\mid p_i)$ likelihood로 weight 갱신
Velocity $r_v = z_v - \hat v$로 velocity residual update $p(z_v\mid v_i)$ likelihood를 weight에 추가 곱
Attitude RPY residual을 tangent/error-state update로 반영 $p(z_{rpy}\mid q_i)$ attitude likelihood를 weight에 추가 곱
먼저 position-only 결과를 비교하고, heading처럼 position만으로 충분히 관측되지 않는 상태를 확인할 때 velocity 또는 attitude measurement를 별도 실험으로 추가합니다.
